# Custom Workspace Rules

## ⚠️ Quy chuẩn định dạng file giao Sếp (BẮT BUỘC)
- **Tất cả các file kịch bản, gói SEO, bài đăng Facebook, kịch bản Shorts** ở mọi công đoạn (cả bản nháp, đề xuất lẫn bản hoàn thiện) khi bàn giao cho Sếp đều **PHẢI** được chuyển đổi sang định dạng **`.docx`** để Sếp đọc được bình thường trên máy tính.
- Các file `.md` chỉ đóng vai trò nháp kỹ thuật nội bộ nằm trong thư mục `scratch/` hoặc `drafts/` và phải được tự động chuyển đổi sang `.docx` bằng script `scripts/md_to_docx_v2.py`.
- Khi trình bày, báo cáo và dẫn link kết quả cho Sếp trong đoạn chat, hãy chỉ dẫn link trực tiếp tới các file `.docx` tương ứng thay vì các file `.md`.
