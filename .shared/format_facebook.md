## 🎯 TỔNG QUAN

Fanpage **Giải Mã 360** là cánh tay nối dài của kênh YouTube **Giải Mã 360**. Mỗi video YouTube → sinh ra 1 bài đăng Facebook tương ứng. Bài Facebook KHÔNG phải copy-paste kịch bản, mà là **chuyển thể** cho nền tảng lướt nhanh.

### So sánh YouTube vs Facebook

| Thuộc tính | YouTube (Kịch bản) | Facebook (Bài đăng) |
|---|---|---|
| **Độ dài** | 1200-1600 từ | 500-800 từ |
| **Format** | Bảng 2 cột [Visual / Audio] | Văn xuôi, giãn dòng mobile |
| **Xưng hô** | "các bác", "bà con", "chúng ta" | "anh em", "các anh em" |
| **Cấu trúc** | 6 phần (Hook → Cầu nối → Dẫn dắt → Thân bài → Cao trào → Kết) | 4 phần (Hook → Bối cảnh → Insight → CTA) |
| **Tag kỹ thuật** | [HOOK], [VÍ VON], [NHẬP VAI]... | KHÔNG có tag |
| **Kết bài** | Kết thúc mở − câu hỏi gây tranh cãi | CTA cụ thể + Hashtag + Link video |

### Quy tắc Chuyển thể (Condensation Rules)

| Giữ lại | Bỏ đi | Chuyển đổi |

| Hook (gọt xuống 50-80 từ) | Pacing Marker | Xưng hô: "các bác/bà con" → "anh em" |

## ⏰ HẸN GIỜ ĐĂNG TỰ ĐỘNG

### Mặc định: 19:00 GMT+7

Khi chạy Bước 6d ở Chế độ A (chuyển thể từ YouTube):
- Bài Facebook sẽ được **hẹn giờ đăng lúc 19:00 VN** (giờ prime-time Facebook)
- Nếu thời điểm hiện tại đã qua 19:00 → hẹn 19:00 ngày hôm sau
- Sếp có thể ghi đè bằng cách chỉ định thời gian khác

### Tính Unix Timestamp cho 19:00 VN
```powershell
# Hẹn 19:00 hôm nay (hoặc ngày mai nếu đã qua 19:00)
$now = [DateTimeOffset]::Now
$target = [DateTimeOffset]::new($now.Year, $now.Month, $now.Day, 19, 0, 0, [TimeSpan]::FromHours(7))
if ($target -lt $now) { $target = $target.AddDays(1) }
$unixTimestamp = $target.ToUnixTimeSeconds()
```
